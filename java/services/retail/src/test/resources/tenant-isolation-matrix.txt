# retail is AfroTransact's first-party (1P) business: one tenant, no seller/provider/customer rows. Every use case calls PermissionChecker.require(retail:*); retail:* permissions are granted only to platform.* roles (identity V10__retail_permissions.sql). Residual: no principal-type check, so a non-staff token holding a retail:* permission would pass.
