# Tenant isolation matrix for catalog-service (prod runs without OpenFGA: RBAC permission + signed org claim).
# Sellers hold catalog:write only; catalog:moderate / catalog:taxonomy / tax:* are held by platform staff roles (identity seed V2),
# so those routes are STAFF_ONLY by permission. catalog:read is held by service tokens.
# Format: METHOD /path | CLASS | enforcement | testClass
