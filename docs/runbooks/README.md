# Runbooks

**Deploying release-1: start at [Release 1 go-live](release-1-go-live.md)** — UAT first (the dry run), then PROD, the same steps; it also holds
image trust, rollback, day 2, vendor questions, known gaps and the launch-readiness checklist. Production is two deployables
(`afrotransact-core`, `afrotransact-go`) on one OVH Managed Kubernetes node, Postgres and Valkey on Layerbase, the web apps on Cloudflare Workers.

One page per alert (below), plus operational procedures. Every alert's `runbook_url` annotation points here (rules in
`infra/observability/rules/`).
