This catalogue has the same shape as `GET /v1/tools` on the mcp-server. The build snapshots it from the
service's `@McpTool` methods and `ToolCatalog` (or from `$MCP_TOOLS_URL/v1/tools` when that variable is set at
build time). Point the form at a running mcp-server to load the live list.
