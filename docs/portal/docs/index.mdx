The portal is generated from the monorepo on every build. Contracts come from `contracts/`, service pages from
each service's `README.md`, guides from `docs/engineering/` and `CLAUDE.md`, runbooks from `docs/runbooks/` and
the backlog from `docs/backlog/backlog.csv`, so there is nothing to keep in sync by hand.
