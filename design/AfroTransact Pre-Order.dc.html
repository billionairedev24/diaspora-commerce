Community Runs: pre-order delivery for cities outside our daily routes

People in a far city pre-order together. Once a run has enough orders we send one shipment, and every shopper pays the same $7.99 flat delivery. Pre-order can be switched on or off for the whole platform or for each city.

Metro cities: daily delivery

No change here. Order any time, it arrives next day, $7.99 flat. Shoppers in these cities see a "Send to family" placement for run cities.

Run cities: scheduled community runs

Each city has a community group and a run that repeats on a schedule. A run ships only once it reaches its minimum order count, so one consolidated shipment covers the distance.
